# Smart Student Library Management System

A CLI-based Java application designed for managing library books, tracking borrowings, and persisting records via file I/O.

## Prerequisites
* Java Development Kit (JDK 17 or higher)
* Apache Maven 3.8+

## Setup & Environment
Clone the repository and navigate to the project directory:
```bash
git clone [https://github.com/YOUR_GITHUB_USERNAME/java-library-management-system.git](https://github.com/YOUR_GITHUB_USERNAME/java-library-management-system.git)
cd java-library-management-system
